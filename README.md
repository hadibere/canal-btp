# CANAL-BTP

**La plateforme de confiance pour vos projets de construction et rénovation**

CANAL-BTP est une application web moderne qui met en relation particuliers et professionnels du bâtiment de manière simple, fiable et sécurisée.

## 🎯 Objectif

Créer une plateforme de référencement des professionnels du bâtiment permettant :
- Aux entrepreneurs (artisans, entreprises de BTP) de gagner en visibilité et trouver de nouveaux clients
- Aux particuliers de trouver facilement une entreprise de confiance pour leurs travaux

## ✨ Fonctionnalités

- ✅ Vérification des entreprises inscrites
- ✅ Présentation des réalisations professionnelles
- ✅ Système d'avis clients avec droit de réponse
- ✅ Messagerie sécurisée pour faciliter la mise en contact
- ✅ Interface responsive (mobile, tablette, desktop)

## 🚀 Technologies

- **Next.js 16.0.5** - Framework React avec App Router
- **React 19.2.0** - Bibliothèque UI
- **TypeScript** - Typage statique
- **Tailwind CSS 4** - Framework CSS utilitaire
- **Responsive Design** - Optimisé pour tous les appareils

## 📦 Installation

Cloner le projet et installer les dépendances :

```bash
npm install
```

## 💻 Développement

Lancer le serveur de développement :

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🏗️ Build

Créer une version optimisée pour la production :

```bash
npm run build
```

Lancer la version de production :

```bash
npm start
```

## 📱 Design Responsive

Le site est entièrement responsive et optimisé pour :
- 📱 Mobile (< 640px)
- 📱 Tablette (640px - 1024px)
- 🖥️ Desktop (> 1024px)

## 🎨 Structure du site

- **Header** : Navigation responsive avec menu burger mobile
- **Hero** : Section d'accueil attractive avec appels à l'action
- **Professionnels** : Présentation des avantages pour les artisans
- **Particuliers** : Guide en 4 étapes pour les clients
- **Fonctionnalités** : Mise en avant des services de la plateforme
- **CTA** : Section d'appel à l'action
- **Footer** : Informations de contact et liens légaux
